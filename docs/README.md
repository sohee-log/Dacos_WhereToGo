3. 작업 중에는 자기 역할 문서만 보면 된다. 배경이 필요할 때만 `PLAN.md`로 돌아온다

## 절대 어기면 안 되는 것

| # | 규칙 |
|---|---|
| **R1** | 협업 필터링(CF)을 쓰지 않는다 — 개인화 근거는 `segment_affinity` 통계 |
| **R2** | 좌표/지역을 먼저 확정하지 않는다 — 처음부터 POI 단위로 후보를 뽑는다 |
| **R3** | 리뷰를 온라인 LLM에 태워 후보를 고르지 않는다 — 오프라인 배치로 구조화 속성을 뽑는다 |
| **비용** | 결제수단 등록이 필요한 서비스는 전부 금지 |
| **NULL** | `hotspot_code`가 NULL인 POI에 `live_*` 점수 0을 주지 않는다 (가중치 재정규화) |
