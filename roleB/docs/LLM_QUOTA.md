# LLM 무료 티어 한도 실측 (B1-5)

> **상태: 미측정.** LLM 조달 경로(제공자·키)가 확정되면 아래 절차로 재고 이 문서를 갱신한다.
> 측정 스크립트는 `roleB/tools/llm_quota_probe.py`에 준비되어 있다.
>
> **이 문서가 비어 있으면 A의 W3 배치 일정을 산정할 수 없다.** W1 안에 채운다.

---

## 왜 W1인가

무료 LLM의 병목은 비용이 아니라 **분당(RPM)·일일(RPD) 호출 제한**이다.
그리고 이 두 숫자가 A의 속성추출 배치가 며칠 걸리는지를 그대로 결정한다.

```
T1 목표 800 POI × POI당 1회 호출 = 800 콜
  일일 한도 200회면 → 4일
  일일 한도  50회면 → 16일   ← 6주 일정에서 T1을 800에서 400으로 줄여야 한다
```

즉 이 숫자는 **엔진의 문제가 아니라 프로젝트 범위의 문제**다. 늦게 알수록 대응이 비싸다.

## 측정 절차

```powershell
cd roleB
pip install -r requirements-dev.txt

$env:LLM_API_KEY  = "..."
$env:LLM_BASE_URL = "https://.../v1"     # OpenAI 호환 엔드포인트
$env:LLM_MODEL    = "..."

# 1차: 작게 때려서 분당 상한을 찾는다 (--confirm 없이는 호출이 나가지 않는다)
python tools/llm_quota_probe.py --rpm-probe 20 --interval 1 --confirm

# 429가 안 나면 상한을 못 찾은 것이다. 올려서 다시 잰다
python tools/llm_quota_probe.py --rpm-probe 60 --interval 0.5 --confirm --out docs/llm_quota_report.json
```

- 스크립트는 응답 헤더(`x-ratelimit-*`, `retry-after` 등)를 함께 수집한다. 제공자가 헤더로
  한도를 알려주면 실측 없이도 일일 한도를 알 수 있다.
- **일일 한도는 한 번의 실행으로 나오지 않는다.** 헤더에 없으면 배치를 하루 돌려 보고
  끊긴 지점의 누적 호출 수를 여기 적는다.

## 이 숫자로 결정되는 것

### 1) A의 속성추출 배치 소요일 (ROLE_A W3)

```
소요일 = (T1 POI 수 × POI당 호출 수) / 일일 한도
```

| 일일 한도 | 800 POI 소요 | 판정 |
|---|---|---|
| 500+ | 2일 이내 | 여유. T2까지 확장 검토 |
| 200 | 4일 | ✅ 계획대로 |
| 100 | 8일 | ⚠️ W3 착수를 W2로 당긴다 |
| 50 이하 | 16일+ | 🚩 T1을 이태원·한남 2개 동으로 축소 (PLAN.md §8.2) |

### 2) 배치 백오프 설정 (ROLE_A · PLAN.md §9.3①)

- 429를 받으면 exponential backoff, `Retry-After`가 오면 그 값을 우선한다
- 일일 한도에 닿으면 **에러가 아니라 정상 종료**한다. `poi.attr_extracted_at IS NULL`
  조건 덕분에 다음날 그대로 이어서 재개된다

### 3) 온라인 설명 생성의 캐시 의존도 (B5-3)

일일 한도가 낮을수록 `explanation_cache` 히트율이 중요해진다.
한도가 100 미만이면 **발표 전날 캐시 워밍(B6-4)이 선택이 아니라 필수**다.

## 제공자를 고를 때 확인할 것

| 확인 항목 | 이유 |
|---|---|
| **결제수단 등록 없이 쓸 수 있는가** | §0.1 하드 제약. 크레딧 방식은 실수 한 번에 과금된다 |
| 한도 초과 시 **과금인가 차단인가** | 차단이어야 무료다 |
| JSON 스키마 강제 출력을 지원하는가 | 속성추출 배치가 이걸 전제로 한다 (PLAN.md §7) |
| 한국어 품질 | 후기 문장에서 속성·감성을 뽑아야 한다 |
| OpenAI 호환 엔드포인트인가 | 호환되면 `llm_quota_probe.py`와 W5 `explain.py`를 그대로 쓴다 |

> 호환 엔드포인트가 아니면 `tools/llm_quota_probe.py`의 `call_once()` 하나만 갈아끼우면 된다.
