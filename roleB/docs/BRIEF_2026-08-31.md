### 🔴 1. Render가 재배포되지 않았다 — **C 또는 팀장이 눌러야 한다**

PR #43~#47이 `main`에 머지된 지 한 시간이 넘었는데 배포본은 **아직 옛 빌드**다.
`render.yaml`에 `autoDeploy: true`가 있지만 대시보드 설정이 우선한다.

확인하는 법 — 배포본에 추천을 한 번 부르고 `score`를 본다.

```
옛 빌드  1번 0.8603 · 4번 0.8808   (점수 순이 아니다) · 약 3.3초
새 빌드  점수 내림차순                                · 1초 안팎
```

**Render 대시보드 → wheretogo-api → Manual Deploy → Deploy latest commit.**
이걸 안 누르면 어제오늘 고친 것이 **화면에 하나도 반영되지 않는다.**
(자동 배포가 꺼져 있다면 Settings → Build & Deploy → Auto-Deploy를 Yes로.)
