|---|---|---|---|
| 1 | `403  error code: 1010` | 앞단 Cloudflare가 기본 UA(`Python-urllib/3.x`)를 차단 | 요청에 **`User-Agent` 헤더** |

`requests` / `httpx`를 쓰면 1번은 자동으로 안 걸린다(자기 UA를 붙인다). `urllib`이면 걸린다.

```python
    "json_schema": {"name": "poi_attributes", "strict": True, "schema": {...}}
  }
}
# headers: Authorization: Bearer <KEY>  +  User-Agent: <아무 문자열>
```

**소요 계산은 그대로다** — POI당 1,038토큰 / 2.3초, T1 800 POI = 직렬 31분 / 동시 8이면 4분. 동시성은 8로 시작하고 429가 나면 절반으로. 게이트웨이가 rate limit 헤더를 안 주므로 **배치에 누적 카운터를 넣고 끊긴 지점을 기록**해야 한다.
