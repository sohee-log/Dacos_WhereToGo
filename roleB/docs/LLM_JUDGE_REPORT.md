`context_fit`(0.13)이 실제로 후보를 바꾸려면 `poi.outdoor_exposure`가 있어야 한다. 지금 실제 관측은 2.1%뿐이고 나머지는 DDL 기본값 0.0이라 **날씨가 순위를 못 바꾼다** — 가중치가 아니라 데이터 문제다 (A 대기).
